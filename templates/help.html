How to use the Expense Tracker

Welcome — this page provides a short guide to help you get the most out of the expense tracker.

The Dashboard

The dashboard displays an analysis of your spending. Use the month selector to view a pie chart for a specific month (if you have records for that month). The pie chart shows the percentage of spending by category. Below the chart you'll find a list showing the amount spent in each category and the spending limit you set for that category. If you exceed a category limit, a warning will appear under that category.

Categories

In the Categories section you add the categories you want to track (for example: Food, Utilities, Hobbies). For each category set a monthly spending limit — the app will compare your expenses to that limit and show warnings when you go over budget.

Expenses

Record each transaction in the Expenses section. A typical expense entry includes:

  1. Select the category from the dropdown.
  2. Enter a short description (e.g., "A bag of chips").
  3. Choose the date of the transaction.
  4. Enter the amount spent.
  5. Click the button to add/save the expense.

Tips

  • Use broad categories to keep tracking simple.
  • Set realistic limits so warnings are meaningful.
  • Review the dashboard regularly to spot trends.
